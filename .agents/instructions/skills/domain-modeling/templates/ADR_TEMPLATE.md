# ADR Template

```markdown
# {Short Decision Title}

**Status:** Accepted

{One to three sentences stating the context, decision, and main trade-off.}

## Considered Options

- **{Alternative}:** {Why it was rejected.}

## Consequences

- {Benefit, cost, risk, or constraint.}
```

- Name the file `NNNN-short-title.md`; number independently within the owning `docs/adr/` directory.
- Omit empty optional sections.
- To replace a decision, create a new ADR and change the old status to `Superseded by [NNNN](NNNN-short-title.md)`.
- Change an accepted ADR's date or body only to correct a factual or typographic error that does not alter the decision.
