# Commit and Push

Follow [CONTRIBUTING.md](../../../../CONTRIBUTING.md) for Git conventions.

1. Identify the task's changes, including new files.
2. Propose a branch name and commit plan, including the files and message for each commit. Include any amendment or force push in the plan.
3. Draft the PR title and description from all changes the branch introduces. Follow the [PR template](../../../../.github/PULL_REQUEST_TEMPLATE.md) and append the provided `PR footer` to the description.
4. Present the branch, commit plan, and PR text in the conversation for the user's confirmation.
5. After confirmation, carry out the plan, create or update the draft PR, and return its link.
