# Commit Push

Follow [CONTRIBUTING.md](../../../../CONTRIBUTING.md) for Git conventions.

1. Identify this task's changes, including untracked files.
2. Verify them with the [verify skill](../verify/SKILL.md), unless this task already verified them and they haven't changed since.
3. Plan the branch name, each commit's files and message, and any amend or force push.
4. Draft the PR title and description from every commit on the branch. Follow the [PR template](../../../../.github/PULL_REQUEST_TEMPLATE.md), with your `PR Footer` as its last line. Add the verify skill's report to the Verification section, and keep the evidence for earlier commits that still applies.
5. Show the plan and the PR title and description in chat, then wait for the user to confirm.
6. Commit and push as planned, create or update the draft PR, and return its link.
