# Commit Push

Follow [CONTRIBUTING.md](../../../../CONTRIBUTING.md) for Git conventions.

1. Identify this task's changes, including untracked files.
2. Plan the branch name, each commit's files and message, and any amend or force push.
3. Draft the PR title and description from every commit on the branch. Follow the [PR template](../../../../.github/PULL_REQUEST_TEMPLATE.md), with your `PR Footer` as its last line.
4. Show the plan and the PR title and description in chat, then wait for the user to confirm.
5. Commit and push as planned, create or update the draft PR, and return its link.
