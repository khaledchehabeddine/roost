# Contributing

## Commits

Write each commit as an imperative summary, then a bullet for each change:

```text
<type>: <summary>

- <what changed>

Co-Authored-By: <agent> <email>
```

Types: `feat`, `fix`, `refactor`, `test`, `docs`, `ci`, `chore`.

Add the `Co-Authored-By` line when an AI agent contributed.

## Branches

Name branches `<label>/<short-description>`, using the issue's type label or the closest fit.
