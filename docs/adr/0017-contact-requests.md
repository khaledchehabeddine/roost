# Contact Requests

A contact becomes accepted only when both sides consent, through a request and an acceptance or through two requests that cross. Only a contact acceptance, or the asked side's inbox grant on the requester's session, accepts the contact (ADR 0024). The exception is a message that starts a session from the requester's newer prekey bundle, which accepts even as an ordinary message, because no acceptance can reach the requester's old session.

## Alternatives

- Treat any reply from the asked side as acceptance: a reply sent for context would accept by accident.
