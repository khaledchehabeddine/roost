# v0.4.0

Security and release-hardening milestone for the Rust core.

## Highlights

- Added `cargo-fuzz` targets for identity key parsing, pre-key bundle parsing, and X3DH handshake envelope parsing.
- Added fuzz smoke CI plus supply-chain CI for `cargo audit` and `cargo geiger` unsafe-baseline drift.
- Added `SignedPreKeyBundle::from_bytes`, `OneTimePreKeyBundle::from_bytes`, and explicit `HandshakeEnvelope` wire encoding/decoding.
- Removed public serde derives from `HandshakeEnvelope`; callers use `to_bytes` and `from_bytes`.
- Added crate READMEs for `aether-core`, `aether-crypto`, and `aether-uniffi`.

## Public API Review

- Rust callers can build a full X3DH session from public bundles, serialize the handshake envelope, deserialize it, accept it, and exchange ratcheted messages.
- UniFFI remains focused on storage-backed identity and publication management. X3DH FFI is intentionally deferred.
- No production dependencies were added. Fuzz-only dependencies are isolated under `fuzz/`, which is excluded from the root workspace.

## Release Path

After merge and green CI, create release notes from this file, then tag and push `v0.4.0` through the project commit/push workflow.
