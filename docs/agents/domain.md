# Domain docs

Before exploring a crate or proposing terminology or architecture, use
[`CONTEXT_MAP.md`](../../CONTEXT_MAP.md) to select the relevant `CONTEXT.md` glossaries.
Read only the applicable decisions in `docs/adr/` and `crates/<crate>/docs/adr/`.
Report missing selected glossaries; absent crate ADR directories are normal.

Use the defined vocabulary. Keep glossaries to domain definitions and ADRs to decisions and reasons;
implementation belongs in code and rustdoc. Surface contradictions with current decisions before
changing their contracts.
