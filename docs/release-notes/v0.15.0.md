# Aether v0.15.0

Aether v0.15.0 completes the Core, UniFFI, and signed mobile distribution boundary needed by Relay's
Apple v1 client.

## Highlights

- Bind each Identity to a permanent Identity Key and a rotatable Discovery Key, including mutual
  binding verification, inbox generation, and recipient delivery capability exports.
- Authenticate caller-owned Transport Binding bytes across initial and established Messages while
  keeping transport encoding, admission, and network IO outside Aether.
- Allocate stable signed- and one-time-prekey identifiers within each Discovery Key Epoch and
  preserve their full unsigned 64-bit range in generated Swift and Kotlin bindings.
- Coordinate secure-state changes through recoverable Prepared KeyStore Operations and let separate
  Library Instances rebuild Current State Snapshots from committed Protocol State Blobs.
- Return versioned Evidence Bundles for accepted established-session Messages and provide a
  standalone verifier plus stable Evidence Identity for Backend deduplication.

## Host changes

- Regenerate Swift and Kotlin bindings and adopt the updated records and operation lifecycles.
- Serialize each Prepared KeyStore Operation from prepare through finalize, abort, or recovery with
  one host-owned per-identity actor or lock.
- Persist the exact Transport Binding with each outbound Message and reuse those bytes for receive,
  acknowledgment, and retransmission operations.
- Reset and re-create identities stored by v0.9.0 debug builds. Aether does not migrate that
  pre-release inbox-generation and discovery-key layout.

## Distribution and verification

The release publishes the iOS xcframework archive, Swift Package wrapper, Android AAR and Maven
metadata, CycloneDX SBOM, detached OpenPGP signatures, pinned SHA-256 checksums, public release key,
source record, and signed release-gate evidence from one revision and GitHub Actions run. Consumers
must verify the binary signature, pinned checksum, and expected release-key fingerprint before use.

The workspace is not published to crates.io.
